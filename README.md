# 🛡️ Stay Secure — Women Safety Android Application

**Stay Secure** is an Android safety application built for women, designed to provide instant emergency assistance through SOS alerts, live location sharing, and quick access to trusted contacts. The app aims to bridge the gap between a threatening situation and timely help.

---

## 📖 About the Project

Women's safety remains a critical concern, especially in situations requiring immediate help. **Stay Secure** addresses this by combining real-time location tracking, emergency SMS alerts, and a simple, fast-access interface — so that help is just one tap away.

This project is backed by academic research, published in a peer-reviewed journal (see [Publication](#-academic-publication) section below).

---

## ✨ Features

- 🆘 **SOS Button** — One-tap emergency alert with live location shared via SMS
- 📍 **Live Location Sharing** — Real-time GPS location sent to emergency contacts
- 👥 **Emergency Contacts Management** — Add, edit, and manage trusted contacts
- 🚨 **Alert Mode** — Visual flashing alert to draw attention during emergencies
- 💡 **Safety Tips** — Curated safety tips and guidance screen
- 🔒 Built with a focus on speed and simplicity during high-stress situations

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed ([Installation Guide](https://docs.flutter.dev/install/manual))
- Android Studio / VS Code with Flutter extension
- PHP & MySQL server (for backend)

### Installation

```bash
# Clone the repository
git clone https://github.com/DHARANISIVARAMAKRISHNAN/stay-secure.git

# Navigate to project folder
cd stay-secure

# Install dependencies
flutter pub get

# Run the app
flutter run
```
